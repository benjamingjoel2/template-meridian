# Fonts

Both typefaces are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org), which allows bundling them with a website.

- **Cinzel** (display) — Copyright 2020 The Cinzel Project Authors. https://github.com/NDISCOVER/Cinzel
- **Lexend** (text) — Copyright 2018 The Lexend Project Authors. https://github.com/googlefonts/lexend

To swap typefaces, add your `.woff2` files here and update `fonts` in `meridian.config.mjs`.
